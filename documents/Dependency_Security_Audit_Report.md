# รายงานการตรวจสอบช่องโหว่ของไลบรารีภายนอก (Dependency Security Audit Report)
**มาตรฐานอ้างอิง:** ISO/IEC/IEEE 12207 (กระบวนการประกันคุณภาพ และการทวนสอบ), ISO/IEC 14764:2006 (การบำรุงรักษาประเภทป้องกัน — Preventive)
**รายวิชา:** ENGSE225 Software Evolution & Maintenance

## วัตถุประสงค์ของเอกสาร

เอกสารฉบับนี้รายงานผลการตรวจสอบช่องโหว่ด้านความปลอดภัยของไลบรารีภายนอก (Third-Party Libraries) ที่ใช้กับระบบ Inventory Management System เวอร์ชัน 2.0.1 ด้วยเครื่องมือ pip-audit โดยเทียบกับฐานข้อมูลช่องโหว่ที่อ้างอิงรหัส CVE และสแกนเพิ่มเติมด้วย Trivy บน Docker image

### 2.1 ข้อสังเกตเรื่องวิธีตรวจ

การตรวจในโหมดอ่านรายการแพ็กเกจจากไฟล์ (`-r`) หลังอัปเกรด pip ไม่นับ pip เข้าไปในผลการตรวจ ผล "ไม่พบช่องโหว่" จากโหมดนี้จึงใช้ยืนยันสถานะของ pip ไม่ได้ ผลที่ใช้ตัดสินในรายงานนี้จึงมาจากโหมด `--path` ซึ่งตรวจพบ pip ในทุกสภาพแวดล้อม และตรวจพบช่องโหว่ใน venv ควบคุมได้ถูกต้อง

### 3.6 ช่องโหว่ในไลบรารีที่ pip ฝังไว้ (pip 26.2.1)

pip บรรจุไลบรารีที่ตัวเองใช้ไว้ในโฟลเดอร์ `pip/_vendor/` แทนการติดตั้งเป็นแพ็กเกจแยก pip-audit จึงเห็นเพียง pip และไม่รายงานช่องโหว่ของไลบรารีเหล่านี้ Trivy อ่านรายการจาก `pip/_vendor/vendor.txt` จึงตรวจพบ

| ไลบรารีใน pip | ช่องโหว่ | ระดับ | เวอร์ชันที่แก้แล้วของไลบรารี |
| :--- | :--- | :---: | :--- |
| `urllib3` 2.7.0 | CVE-2026-97687, CVE-2026-97689 | HIGH | 2.8.0 |
| `urllib3` 2.7.0 | CVE-2026-97688 | MEDIUM | 2.8.0 |
| `msgpack` 1.1.2 | GHSA-6v7p-g79w-8964 | HIGH | 1.2.1 |
| `setuptools` 70.3.0 (ฝังไว้เฉพาะส่วน `pip/_vendor/pkg_resources`) | CVE-2025-47273 / CVE-2026-59890 | HIGH / MEDIUM | 78.1.1 / 83.0.0 |

| สภาพแวดล้อม | สถานะ |
| :--- | :--- |
| Docker image | ✅ แก้แล้ว: ถอน pip ออก |
| Development, Build และ venv ที่ผู้ใช้ติดตั้ง wheel | ⚠️ ยังมีอยู่: ต้องใช้ pip ติดตั้งแพ็กเกจ และ pip 26.2.1 เป็นรุ่นล่าสุดบน PyPI ณ วันที่ตรวจ (ตรวจด้วย `pip index versions pip`) จึงต้องรอ pip รุ่นถัดไปที่อัปเดตไลบรารีเหล่านี้ |

ความเสี่ยงอยู่ที่ขั้นตอนดาวน์โหลดและติดตั้งแพ็กเกจเท่านั้น ตัวโปรแกรมไม่ได้เรียกใช้ pip ขณะทำงาน ระหว่างรอ ให้ติดตั้งแพ็กเกจจาก PyPI โดยตรงผ่าน HTTPS และไม่ผ่าน proxy ที่ไม่น่าเชื่อถือ (CVE-2026-97687 เกี่ยวกับการตั้งค่า TLS ของ HTTPS proxy)
